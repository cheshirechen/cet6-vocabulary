# 我的六级单词本（CET-6 Vocabulary）

个人六级真题精读生词本。只积累本人在阅读中最终标记、确认需要背诵的单词和短语，不自动扩充为通用六级词汇库。

**网站：** [https://cheshirechen.github.io/cet6-vocabulary/](https://cheshirechen.github.io/cet6-vocabulary/)

## 一、网站功能与词条整理规范

### 1. 网站功能

| 功能 | 说明 |
| --- | --- |
| 单词列表模式 | 点击「单词列表」切换为紧凑列表，仅展示正式词条的英文单词或短语，不显示音标、释义、底层词、易混词、特殊形式、朗读按钮及出处；点击「详细词条」恢复默认展示。搜索、筛选和排序在两种模式中均可使用。 |
| 词汇搜索 | 支持搜索英文单词、短语、中文释义、底层词和易混词等内容。 |
| 真题出处筛选 | 默认显示全部真题，可按具体年份、月份、套数及阅读篇目筛选。 |
| 易混词筛选 | 点击「仅易混词」，仅显示带有本人标注的易混词的正式词条。 |
| 加入顺序（默认） | 按单词加入单词本的先后顺序展示；同一篇阅读按确认后的词汇录入顺序排列。 |
| A–Z | 按英文字母升序展示。 |
| Z–A | 按英文字母降序展示。 |
| 隐藏释义 | 隐藏词义、例句、底层词释义及易混词等答案信息，点击单个词条可以揭示答案；再次切换可恢复。 |
| 朗读 | 主单词和底层词旁提供朗读按钮，使用浏览器的英语语音合成功能，优先英式发音；实际声音取决于设备和浏览器。 |
| 词条数量 | 显示当前筛选结果数量与全部正式词条数量。 |

搜索、出处筛选、易混词筛选和排序可组合使用。排序只改变显示顺序，不修改数据库的原始录入顺序。

### 2. 单个词条的内容与排列顺序

| 顺序 | 内容 | 展示规则 |
| --- | --- | --- |
| 1 | 单词或短语 | 大字号展示原形，旁边提供朗读按钮。 |
| 2 | 音标 | 主单词下方展示英式 IPA；存在因词性不同而改变读音的情况时分别标明。 |
| 3 | 底层词／构词关联词（可选） | 紧接主单词及音标下方；英文采用接近主单词的字号，附音标、朗读及简明释义；不显示「构词 / 底层词」标题。 |
| 4 | 易混词（可选） | 放在底层词下方、正式释义上方，以独立区域显示；没有底层词时直接放在主单词及音标下方。 |
| 5 | 特殊形式（可选） | 记录不规则复数、特殊动词变形等有记忆价值的形式，必要时附音标。 |
| 6 | 金山词霸 | 按词性分行展示可获取的词典中文释义。 |
| 7 | 双语学习补充 | 不显示「双语学习补充」小标题，直接按词性分组，各词性另起一行；每一义项以①②③编号，先写括号内的简明英文义，再写中文释义，下方附常用搭配或例句及中文翻译。 |
| 8 | 真题出处 | 如「2025年6月第1套 · 仔细阅读 Passage One」，重复出现时保留多个出处。 |
| 9 | 词典查询链接 | 统一链接到剑桥英汉简体词典；短语必要时指向可查阅该用法的主词条。 |

底层词、易混词、特殊形式均为可选字段；没有对应内容时不显示、不留空白。词条不再单独设置「真题语境」字段，也不在每条释义、搭配或附属词旁重复显示核验状态及来源提示。来源说明统一放在网站顶部。

### 3. 各字段的获取及整理方法（最终约定）

| 字段 | 来源与处理方法 |
| --- | --- |
| 正式词条 | 只根据本人发来的最终黄色高亮标记及确认清单收录，包括文章正文和题干、选项中的单词与短语。不得由 AI 主动挑选、扩充或新增未标注词汇。 |
| 单词原形 | 常规人称、时态、分词、复数等变化还原原形；规则变化通常不另外列出。具有独立词性及义项的派生词或固定用法按实际情况保留。 |
| 特殊形式 | 不规则变化同时保留原形和有记忆价值的变形，如 crisis → crises、underlie → underlay / underlain。 |
| 固定搭配及短语 | 将实际高亮的完整短语作为整体词条，如 regardless of、respond to；不随意拆成多个正式词条。 |
| 音标 | 优先参考可访问的权威词典（目前主要为金山词霸）的英式音标；短语缺少完整音标时可按组成词和常见读法整理，不虚称为词典直接提供。 |
| 底层词／构词关联词 | 按真实构词规律、词形关系及词源资料整理；名词、形容词、副词等由较基础的词派生时展示相应底层词，如 instruction → instruct、chronically → chronic。历史词源关联与现代派生关系应区分，如 secretary 与 secret；不强行拆词。 |
| 易混词 | 仅记录本人主动标明的易混词，如 urge / argue、investigate / invest、case / cause；附简明词性和词义，供对比记忆，不由 AI 自行扩展易混词清单。 |
| 金山词霸中文释义 | 直接查阅可访问的金山词霸（爱词霸）词条，保留词典实际提供的简明中文释义、词性及相应顺序，必要时仅做标点、重复内容及排版整理；不能查到时不自行伪造词典释义。 |
| 双语学习补充 | 按最终确定的 AI 归纳方式整理：覆盖常见义项与主要词性，英文释义简洁、放在括号内，中文解释清晰，按词性分组编号；优先参考可获取的词典资料，但允许 AI 归纳词义及补充自然、正确的常用搭配或例句。该部分不是词典逐字转录。 |
| 常用搭配／例句 | 与对应义项匹配，优先典型、高频、适合阅读理解和记忆的表达；附中文翻译。可以参考词典或由 AI 归纳补充，不将自行补充的内容称为词典原文。 |
| 词性 | 使用简写：n.、v.、vt.、vi.、adj.、adv.、conj.、prep.、phr.、phr. v. 等；不同词性分别换行，适当标注可数／不可数等必要语法信息。 |
| 真题出处 | 根据原图记录年份、月份、套数、阅读题型和篇目；不得猜测缺失出处。 |
| 词典链接 | 统一使用剑桥英汉简体词典（Cambridge English–Chinese Simplified Dictionary）入口。该链接用于进一步查询，不代表页面中的所有词义均摘自剑桥词典。 |

**来源区分：** 「金山词霸」是中文词典释义区，「双语学习补充」是 AI 归纳区。词典链接采用剑桥英汉词典，三者不应混为同一来源。若某词无法获取金山词霸释义，暂不显示该词的金山词霸区，不将 AI 归纳填入该区。

**收录边界：** 底层词、易混词与特殊形式属于正式词条的附属信息，不自动增加正式词条数量；只有其本身也被黄色高亮并确认需要独立记忆时，才作为正式词条加入。

### 4. 后续更新规则

1. 阅读精读完成后，本人发送带最终标记的原文和题目截图。
2. AI 按第二部分的规则识别待收录词汇；看不懂的标记、范围不确定的短语或构词／易混关系应先向本人确认，不自行扩大收录范围。
3. 按上述字段规范整理并录入。已存在的词条合并新的真题出处，避免重复建卡；必要时补充本人新标出的附属信息。
4. 保留原有词条的加入顺序，新词追加至数据库末尾。
5. 同步更新 `vocabulary.js` 和 `index.html` 中内嵌的数据库快照，保证网页与数据库一致，避免缓存导致音标显示 undefined、底层词丢失等问题。
6. 提交 GitHub 后检查数据、网页显示与部署状态。

仓库文件：

- `index.html`：静态网站、交互逻辑及词汇数据库快照。
- `vocabulary.js`：词汇数据库，后续整理和更新的主要数据源。
- `README.md`：网站功能、数据来源、阅读标记和更新规范。

GitHub Pages 以 `main` 分支根目录为发布来源，后续持续更新同一个网站。

## 二、我的六级阅读标记规则

阅读时的标记分为初次做题的诊断标记、精读分析笔记和最终收录标记。**只有黄色高亮代表最终选入单词本的正式词条。**

| 标记 | 含义 | 单词本处理方式 |
| --- | --- | --- |
| 黄色高亮 | 精读整理后最终需要记忆、收入个人单词本的单词或短语。 | 收录。按照原形、短语及特殊形式规则处理；正文和题目选项均适用。 |
| 浅蓝色高亮 | 知道该词原本的意思，但在本篇阅读中没有找到合适的语境义，看完翻译才明白。 | 不收录。用于记录语境理解或一词多义方面的问题。 |
| 蓝色圈画（深于浅蓝色） | 初读时不认识该词，或词义记得模糊、不确定。 | 不收录；只有另加黄色高亮才作为正式词条。 |
| 浅蓝色笔记（圈画、其他线条或文字） | 精读时分析本篇阅读原文与题目中同一意思词语用了不同表达的同义替换、错题原因，以及正确与错误选项的区别。 | 不收录；与初读时表示词义不确定的蓝圈区分。 |
| 蓝色波浪线 | 句子结构、短语组合或语义组合不确定；单词可能认识，但不知道如何组合、按自己的理解翻译后觉得不通顺，或不确定理解是否正确。包括长难句、固定搭配和局部结构问题。 | 不收录。用于句法、短语、指代和语义关系分析。 |
| 蓝色直线／下划线 | 题目关键词、原文答案定位及对应依据。 | 不收录。用于分析定位、同义替换和选项语义。 |
| 红色中文批注 | 精读时自己记录的词义、翻译、搭配解释等，便于本人查看。 | 不作为词典释义来源，不直接抄入单词本。 |
| 红色英文批注／明确的易混词标记 | 本人记录的易混词、底层词、构词关联等。例：urge 旁的 argue，investigate 旁的 invest，case 旁的 cause。 | 仅在关系明确时作为对应词条附属信息；不自动新增正式词条。若不确定是易混、构词还是普通笔记，先询问本人。 |
| 黑色笔记 | 精读时对初读未理解的句子结构进行划分和分析，例如括号、箭头、句法成分及修饰关系。 | 不收录。属于句子结构复盘。 |

### 标记冲突及特殊情况

- 蓝圈、浅蓝色高亮、浅蓝色笔记、蓝色直线或其他分析标记与黄色高亮同时出现时，以黄色高亮的最终收录意图为准；其余标记仍保留原来的学习分析意义。
- 黄色高亮也可能出现在手写的词汇批注中。按本人确认的实际收录目标处理，例如 frame 作为正式词条，reframe 作为构词关联信息；underlying 保留其形容词义，同时附 underlie 及特殊变形。
- 蓝圈、蓝色波浪线、蓝色直线和浅蓝色笔记可用于后续阅读能力诊断，但不因其本身而额外增加单词。蓝色和浅蓝色是不同的笔记颜色，不得混淆。
- 红色英文或黑色句法笔记若存在未定义的特殊符号，不默认赋予新含义；需要时先向本人确认。
- 不把 AI 认为重要、可能考查或值得背诵的其他词汇自动收入单词本。
